# Recipe App

A CRUD (Create, Read, Update, Delete) API for managing recipes, built with Node.js, Express.js, and MongoDB. The app follows the MVC architecture and includes API documentation using Postman.

---

## 🌐 API Endpoints

Create a recipe  
`POST /api/recipes/create`

Get all recipes  
`GET /api/recipes/getData`

Get recipe by ID  
`GET /api/recipes/getData/:id`

Update recipe by ID  
`PUT /api/recipes/update/:id`

Delete recipe by ID  
`DELETE /api/recipes/delete/:id`

---

## 🛠 Tech Stack

- Node.js  
- Express.js  
- MongoDB + Mongoose  
- Postman (for API testing and documentation)
